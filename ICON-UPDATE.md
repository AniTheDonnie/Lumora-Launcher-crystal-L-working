# LUMORA Icon Update — Option 1

The launcher now uses the Option 1 Crystal L icon for the Electron window and Windows installer/build configuration.

Files:
- `assets/lumora-icon.png` — window/runtime icon
- `assets/lumora-icon.ico` — Windows executable/installer icon

To see the new icon in the generated EXE, rebuild the Windows package with GitHub Actions after committing/uploading these changes.
