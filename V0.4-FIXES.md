# LUMORA v0.4 Fixed Build

Fixes in this build:
- Home PLAY button now calls the real launcher flow instead of showing a preview alert.
- First PLAY can create a default instance when none exists.
- Added Accounts page with Microsoft sign-in and Offline/Local profile management.
- Microsoft device-code verification page is opened automatically when available.
- Added a right-side Home dashboard so the desktop window is not left with a large blank area.
- Added selected account, selected instance, and Java status to the Home dashboard.
- Added launch-status feedback.
- Fixed a JavaScript/Electron main-process syntax issue in the previous build.
- Updated the visible launcher version to 0.4.

Important:
- Microsoft authentication is required to launch official authenticated Minecraft.
- Offline/Local profiles are launcher profiles; they do not bypass Minecraft ownership or authentication.
- Fabric/Forge/NeoForge/Quilt loader provisioning and some advanced integrations still require further implementation/testing.
